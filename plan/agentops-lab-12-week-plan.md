# AgentOps Lab 보류 안내

> 상태: Deferred
> 보류 결정일: 2026-08-18
> 재검토 시점: 심화과정 핵심 학습 목표를 완료하고 별도 가용 시간이 확보된 이후

AgentOps Lab은 Human·AI Agent의 업무, 권한, 승인, 실행과 운영을 다루는 장기 프로젝트다. 현재 기술 심화 기간에는 제품 범위가 학습 목표에 비해 지나치게 크다고 판단하여 구현 일정에서 제외했다.

## 현재 결정

- 기술 심화 8주는 과정 공지에서 선택한 Java Backend·Web·Database·Security·Test·AI Native 학습에 사용한다.
- 공통 실습 대상은 작은 `AI Helpdesk Learning Lab`으로 제한한다.
- AgentOps Lab 제품 저장소와 설계 문서는 변경하거나 학습 성과로 계산하지 않는다.
- 핵심 학습을 완료한 뒤 시간이 남더라도 자동으로 재개하지 않고 새 범위와 기간을 다시 검토한다.

## 재개 조건

- Java·Spring·PostgreSQL의 핵심 흐름을 직접 설명하고 Test로 검증할 수 있다.
- 인증·인가, LLM 실패 처리와 기본 운영 경계를 작은 서비스에서 확인했다.
- 최소 범위, 예상 기간과 단독 구현 가능성을 새로 산정했다.
- 취업 활동과 현재 과정 제출물을 침해하지 않는다.
