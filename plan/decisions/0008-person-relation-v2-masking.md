# ADR 0008 인물 관계를 보존하는 V2 독립 치환

> 상태: Accepted — 로컬 독립 치환기 범위. Provider 전송 형식과 Main 조립은 Draft
> 결정일: 2026-10-19
> 근거: SAME의 추이 모순 거부·구조 검증과 원문 내용 평가 구분의 문답, 이어서 구현 요청

## Context

V2 구조 검증기는 등장 위치와 관계의 일관성을 검사하지만 전송용 복사본은 만들지 않는다. 모든 이름을 같은 표시로 바꾸면 다른 사람의 정보 노출을 표현하기 어렵고, 모든 등장 위치에 다른 사람 번호를 붙이면 SAME과 미확인 관계를 왜곡한다. DB 원문과 V1의 기존 처리 경로는 유지해야 한다.

## 검토한 선택지

- 공통 PERSON 표시 하나: 실명은 가리지만 사람 사이의 관계를 잃는다.
- 등장 위치마다 다른 사람 표시: 같은 사람의 반복 등장과 미확인을 다른 사람으로 오인하게 한다.
- SAME 집합별 표시와 별도 관계 목록: 확인한 동일인만 묶고 DIFFERENT·UNDETERMINED를 유지할 수 있다.

## Final Decision

세 번째 안을 독립 `AiPrivacyScanResultV2Masker`로 구현한다. 같은 호출의 불변 Title·Body로 V2 검증과 치환을 함께 진행하며, 다른 원문에서 검증한 `ValidatedScan`을 따로 받지 않는다. 검사 Process의 입력과 응답을 같은 호출로 결합하는 책임은 후속 Preparer 연결에서도 유지한다.

SAME으로 연결된 위치는 첫 등장 순서의 `[PERSON_1]` 같은 표시를 공유한다. 다른 SAME 집합에는 다른 표시를 쓰되, 그 사이의 명시적인 DIFFERENT·UNDETERMINED를 반환한다. 서로 다른 표시는 확인된 동일인 집합이 다르다는 뜻일 뿐, 미확인 관계를 DIFFERENT로 바꾸지 않는다. 출력 관계는 집합별 쌍으로 중복 제거하고 숫자 순으로 정리한다.

번호는 호출 안에서만 생성한다. 이름 문자열을 비교하거나 문의 간 신원을 연결하지 않는다. 반환값은 치환한 제목·본문과 생성 표시 사이의 불변 관계 목록이다. 실명 역변환 목록·원본 위치·Scanner의 등장 번호는 반환하지 않는다. 탐지에서 놓친 정보가 남을 수 있어 결과의 `toString()`도 내용을 숨긴다.

원문에 예약 접두사 `[PERSON_`가 있으면 결과 전체를 고정 `InvalidScanResultException`으로 거부한다. 표시처럼 보이는 사용자 문자열을 신뢰하거나 지우지 않는다. Escape나 별도 구조화 본문은 Provider 표현 변경까지 필요하므로 이번 독립 단계에서는 채택하지 않는다. 정상적인 설명 문장도 이 접두사를 포함하면 AI 준비가 거부될 수 있다는 가용성 비용을 기록한다. 이미 접수한 원문을 변경하거나 원문 그대로 전송하는 대안은 두지 않는다.

제목·본문을 합친 치환 후 UTF-8 Byte 상한을 생성자로 명시한다. 원문 구간과 표시를 붙이기 전에 남은 상한을 검사하며, 결과 전체의 무제한 Byte 복사본은 만들지 않는다. 관계 개수는 기존 V2 상한으로 제한한다. 이 텍스트 상한은 전체 직렬화 HTTP Body의 상한이 아니며 배포 기본값도 확정하지 않는다.

## Rationale

검증한 관계를 치환 과정에서 잃거나 새 관계로 추측하지 않는다. 원문을 다시 쓰는 모델 대신 Java가 검증한 범위만 바꾸고, 호칭·복구 사실·영향 인원·마감 등 나머지 문자를 보존한다. 기존 Guard를 제거하거나 V2를 Main에 먼저 연결하지 않아 검토 중인 전송 표현을 운영 계약으로 확정하지 않는다.

## Validation과 Follow-up Review

Lab `e617823`에서 새 치환 Test 37개와 앞선 핵심 402개를 합친 439개가 통과했다. 같은 이름의 DIFFERENT·SAME·UNDETERMINED, 두 SAME 집합과 미확인 관계, Unicode 위치·문자 보존·표시 충돌·치환 후 Byte 상한을 확인했다. PostgreSQL 20개는 기존 V1 회귀이며 V2→DB 검증이 아니다.

다음은 기존 Known Fragment Guard가 새 표시를 다시 치환하지 않도록 하는 검증과 관계 정보를 보존하는 Provider 입력 형식이다. 실제 모델의 탐지·관계 정확도, Linux 실행/회수·전체 자원·Main 연결은 별도 Gate로 유지한다. 구조가 일관된 잘못된 SAME을 이 치환기가 고쳐 주지는 않는다.
