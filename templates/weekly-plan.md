## Learning Evidence Gate

- [ ] 핵심 질문에 답하는 설명이 있다.
- [ ] 실행 전에 예상 결과와 실패 조건을 기록했다.
- [ ] 정상·경계·실패 중 필요한 Case를 직접 재현했다.
- [ ] Test, Trace, Header, Query Plan, Metric 또는 Dataset 근거가 있다.
- [ ] 예상과 달랐던 점과 원인을 설명했다.
- [ ] AI 도움 없이 작은 변경과 관련 Test를 수행했다.
- [ ] 적용·독립 Spike·보류·제외 선택의 이유가 있다.
- [ ] 완료·부분 완료·미수행 범위를 구분했다.
- [ ] Secret, 개인정보, 내부 URL과 로컬 경로가 공개 자료에 없다.
